## 한 줄 결론

다이어트카·와탕카·카브릿지는 **하나의 법인, 하나의 매물 DB, 세 개의 파사드**다. watangcar.com은 dietcar.com과 홈페이지·매물번호(m_no)·카운터가 완전히 동일한 거울이고, carbridge.co.kr은 이미지·매물번호를 dietcar.com에서 그대로 끌어오는 화이트라벨 스킨이다. 승계 자체는 **플랫폼을 거치지 않는다** — 협의가 끝나면 두 당사자가 리스사 지점에 함께 방문해 계약서를 쓰고, 정산도 그 자리에서 끝난다[확인, `/images/sub/5_3_img02.png`]. "구매안전서비스"는 차량 대금 에스크로가 아니라 농협이 제공하는 통신판매 결제대금(광고비·이용권) 소비자보호 인증이며, 그 인증서 자체가 2017년 발급 이후 갱신되지 않은 채 방치돼 있다[확인]. 승계지원금은 **부호 있는 단일 필드**(인수비용, 음수=매도자가 지급)로 이미 실매물에 들어가 있어[확인, m_no=32582], 차용의 `carryoverPremium: nonnegative()` 제약이 막는 매물이 지금 이 순간에도 팔리고 있다는 뜻이다. 승계차량 평가점수는 **리스와 렌트가 서로 다른 배점표**를 쓰고, 조회수가 점수의 10%를 차지해 인기와 품질을 섞는다[확인, `popup_estate.html`]. 사이트 자체의 특허 상태 표기가 페이지마다 다르고(PC는 "출원 中", 모바일은 "등록"), 사업자 주소도 세 출처(웹 푸터/모바일 앱스토어/구매안전서비스 확인증)가 서로 다르다 — 1세대 사이트답게 오래된 콘텐츠가 정리되지 않은 채 누적된 흔적이다.

## 1. 역할과 돈의 흐름

세 방향의 현금 흐름이 있다. 차량 대금 자체는 플랫폼을 통과하지 않는다(§5 참조).

| 흐름 | 방향 | 상품 | 시점 | 근거 |
|---|---|---|---|---|
| 매도자 → 다이어트카 | 광고비(선불) | 추천매물/추천매물플러스 이용권, 기간연장권 | 구매 즉시(2개월 단위 선불) | [확인] `/guide/sellguide4.html` |
| 매도자 → 다이어트카 | 대행 수수료 | 프리미엄 승계대행 4%(VAT포함, 거래가격 기준) | **후불** — "정산" 단계에서 차감 추정 | [확인] 모바일 `sell04.html` |
| 매도자 → 다이어트카 | 대행 선입금+정액 수수료 | 단순 승계대행: 선입금 60만원(VAT별도, 수도권 기준, 심사 후 미진행 시 70%환급) **+** 최종 수수료(거래가격 4천만원 미만 66만원 / 이상 110만원, VAT포함) | 선입금은 신청 시 선불, 최종 수수료는 거래가격 확정 후 | [확인] 모바일 `sell04.html` — 두 금액이 같은 페이지에 별도 항목으로 존재. 기존 랜드스케이프 문서는 60만원만 기록했었다 |

| 매도자 ↔ 인수자 | 승계지원금/인도금(우리 표준어) | 실제 차량 승계 대금 — 신호 있는 단일 필드로 매물에 노출 | 계약서 작성·리스사 정산 시점(플랫폼 미개입) | [확인] m\_no=32582 "인수비용 -500,000원" |

- **매도자(리스이용고객)**: 승계할 계약을 등록.

- **다이어트카 매니저**: 등록·심사·정산 대행자. 실명(예: "매니저(다이어트카닷컴) 010-****-****(문서에서 마스킹)")으로 매물에 노출됨[확인, m\_no=32582].

## 2. 매도자 여정

1. **선택**: 무료 직접등록(PC 전용) vs 유료 추천매물 vs 승계대행(프리미엄/단순) vs 다이어트카에 직접 매각(리스차 매입) — 4갈래.
2. **등록**: 무료는 회원가입 후 본인이 정보 입력. 프리미엄 대행은 다이어트카 직원이 출장 방문해 사진 촬영 후 대신 등록[확인, `sell04.html` STEP1].
3. **관리자 검수**: FAQ 명시 탈락 기준 — 상세설명 무내용, 사진 없음/번호판 노출 안 됨, **미회수원금 미표시**, **납부일자 미표시**, **승계수수료 부담 주체 미고지**[확인, `5_faq.html`]. 통과 시 "서류검증완료" 배지 부여 여부는 별도 판단(§7).
4. **노출**: 무료 등록은 승계평가 점수·상세설명·특허플랫폼(계산기)·동시광고 중 **아무것도 받지 못한다** — 모바일 `sell02.html`의 기능 비교표가 X로 명시. 유료 추천매물부터 입력대행·상세설명·승계평가가 붙고, 추천매물플러스에서만 동시광고가 붙는다[확인].
5. **매칭**: 인수자가 신청하면 매도자에게 SMS·이메일로 연락처 발송[확인, `5_3_img02.png`].
6. **조건 협의**: 당사자 직접 협의 또는 승계대행 의뢰.
7. **승계대행 신청(선택)**: 협의 완료 후 다이어트카에 연락 → 서류 대행 접수 → 리스사에 심사 의뢰.
8. **계약서 작성**: **매도자와 인수자가 함께 해당 리스사 지점에 방문**해 계약서 작성[확인].
9. **정산**: 리스사 승계절차 완료(자동차세·리스료 정산 → 승계계약서 서명 → 보험가입·질권설정 → 이행보증금 납부 → 승계수수료 납부 → 승계전산처리 → 승계확인서 발급 → 자동차보험 해지, 8단계)[확인, `/guide/process.html`].
10. **후기**: 사용후기 게시판(별도 평점 시스템 없이 텍스트 후기, 최신 3건이 메인 노출)[확인].

## 3. 인수자 여정

1. **탐색**: PC 6개 탭(스페셜 추천/추천가능 직영차/승계차 평가/현금받는 승계/보증금 전액할인/렌트 승계) 또는 모바일 4개 필터(전체/스페셜 추천/보증금 전액할인/현금받는 승계).
2. **비교**: 관심차량(찜) 등록, 동급차량 추천 카드(같은 모델의 다른 매물 4~5건, 잔여개월·월리스료만 요약).
3. **상세 확인**: 매물 상세 페이지에서 리스이자 계산기·현금구매 비교·승계차량 평가정보·심사기상도 확인(§7, §8).
4. **서류 확인**: 로그인해야 렌트 스케줄표·등록증·보험이력 열람 가능(비로그인은 잠김 아이콘만 노출)[확인].
5. **신청**: "상담문자 보내기" 또는 "승계상담신청"으로 접촉. 문의 폼 필드는 상담유형(승계상담/판매/구매), 승계상담분류(리스/렌트), 차량종류(제조사·모델·등급·세부등급), 주행거리, 색상, 사고유무, 옵션, 신청인 정보(이름·지역·휴대폰·전화·이메일), 상담내용, 캡차[확인, `5_complaint.html`] — 이 폼은 로그인 없이 접근 가능하나, **본 조사는 실제 제출을 하지 않았다**(브리프 금지 항목).
6. **매니저 연결**: 승계신청 시 담당 매니저가 배정되어 조건 조율.
7. **심사**: 리스사 심사(신용 등) — 심사기상도로 사전 난이도 안내.
8. **계약**: 리스사 지점에서 계약서 서명, 자동차보험 가입, 질권설정.
9. **인수 완료**: 승계확인서 발급.

## 5. 거래 흐름: 승계 신청 → 심사 → 진단 → 예치 → 명의이전 → 정산

**플랫폼 자체 흐름**(`/images/sub/5_3_img02.png`, [확인]):

```
판매자: 승계차량등록 → 구매자연결(직/간접) → 승계조건협의(직접협의/승계대행)
구매자: 승계신청및검색 → 판매자연결(SMS·이메일 발송) → 승계조건협의(직접협의/승계대행)
                 ↓ (양쪽 협의 완료)
협의완료후 승계대행 신청 → 승계심사대행(리스사 심사 의뢰) → 계약서 작성(양측이 리스사 지점 내방)
                 → 리스사 승계절차후 승계완료(심사승인, 계약서작성, 비용정산 종료)
```

**리스사 내부 8단계**(`/guide/process.html`, [확인]): ① 자동차세 및 리스료정산 → ② 승계계약서 서명날인 → ③ 보험가입 및 질권설정 → ④ (前) 이행보증금 납부 → ⑤ (後) 승계수수료 납부 → ⑥ 승계전산처리 → ⑦ 승계확인서 발급 → ⑧ (前) 자동차보험 해지.

**프리미엄 승계대행 전용 7단계**(`sell04.html`, [확인]): 출장등록 → 승계자연결 → 심사 → 심사완료 → 정산 → 인수(차량점검) → 완료보고.

**단순 승계대행 5단계**(`sell04.html`, [확인]): 서류안내 → 심사대행 → 승인확인 → 계약서 작성 대행 → 정산/승계완료.

**[판단] 예치(에스크로) 단계가 없다.** 위 세 흐름 어디에도 "다이어트카가 대금을 보관했다가 지급한다"는 단계가 없다. "정산"은 매니저가 보증금·월리스료 등 계약 정보를 양측에 정확히 알려주는 **정보 중개**를 의미하며(모바일 `sell04.html` "구매자와 판매자에게 정확한 계약정보를 제공하여… 정확하고 투명하게 정리하여 알려드립니다"), 실제 자금 이동은 §8(d)에서 다룬다.

**상태명**: dietcar는 명시적 매물 상태 enum을 노출하지 않는다. 탭 구분(스페셜 추천/직거래/직영/현금받는 승계 등)이 상태가 아니라 **카테고리**이고, "승계완료" 카운터만 집계로 노출된다. 차용의 `ListingStatus`(DRAFT/PENDING/ACTIVE/RESERVED/SOLD/HIDDEN/REJECTED) 같은 세분화된 상태 머신에 대응하는 개념이 없다[판단].

## 7. 검증·신뢰 장치

### 7.1 서류검증완료 / 승계대행프리미엄 배지
매물 상세 페이지 하단에 정의가 직접 적혀 있다[확인, m\_no=32582]:
- **서류검증완료**: "승계전문가의 꼼꼼한 서류확인, 등록된 정보가 모두 사실임을 확인"
- **승계대행프리미엄**: "승계자를 위해 상담,심사,성능점검,세차,정산 등 계약 전과정 대행서비스"

두 배지는 독립적으로 붙는다(예시 매물은 둘 다 보유). **[판단]** "서류검증"은 사람이 서류를 눈으로 확인했다는 뜻이지, 자동화된 검증이 아니다.

### 7.2 승계차량 평가점수 — 리스와 렌트가 다른 배점표
`popup_estate.html` 원문[확인]. **기존 랜드스케이프 문서(§2.3)의 "월렌트료 30/현금지원금 30/사고유무 20/주행거리 10/조회수 10"은 렌트차량 전용 배점표였다.** 리스차량은 별도 배점표를 쓴다.

**리스차량 평가기준** (합 100):
| 항목 | 배점 조건 | 점수 |
|---|---|---|
| 판매가격 vs 중고차시세 | 가격 낮음 / 시세와 동일 / 가격 비쌈 | 30 / 25 / 20 |
| 이자율 vs 기준 평균금리 | 금리 낮음 / 평균금리 / 금리 비쌈 | 20 / 15 / 10 |
| 월리스료 vs 기준 평균 리스료 | 낮음 / 평균 / 비쌈 | 10 / 5 / 0 |
| 사고유무 | 무사고 / 단순수리 / 사고있음 | 20 / 15 / 5 |
| 주행거리 vs 기준 평균 | 낮음 / 평균 / 높음 | 10 / 5 / 0 |
| 조회수 vs 기준 평균 | 높음 / 평균 / 낮음 | 10 / 5 / 0 |

**렌트차량 평가기준** (합 100, m\_no=32582가 실제로 이 표를 사용 — 25/25/15/5/10=80):
| 항목 | 배점 조건 | 점수 |
|---|---|---|
| 월렌트료 vs 기준 평균 | 낮음 / 평균 / 비쌈 | 30 / 25 / 20 |
| 현금지원금 vs 기준 평균 | 많음 / 평균 / 적음 | 30 / 25 / 20 |
| 사고유무 | 무사고 / 단순수리 / 사고있음 | 20 / 15 / 5 |
| 주행거리 vs 기준 평균 | 낮음 / 평균 / 높음 | 10 / 5 / 0 |
| 조회수 vs 기준 평균 | 높음 / 평균 / 낮음 | 10 / 5 / 0 |

**[판단]** 두 표 모두 "조회수"가 배점의 10%다. 즉 이 점수는 순수 매물 품질 지표가 아니라 **인기도가 섞인 지표**다. 또한 "평균"의 기준 모집단(전체 매물? 동일 모델? 기간?)이 어디에도 공개되지 않아 재현 불가능한 블랙박스다.

**§2 참조**: 무료 직접등록 매물은 이 점수 자체를 받지 못한다(§2, 모바일 `sell02.html` 기능표) — 평가점수는 유료 등급 이상의 특전이다.
