## 한 줄 결론

엔카·KB차차차는 승계를 **직접 중개하지 않고 광고·필터 레이어로만** 흡수한다 — 엔카는 카드에 "승계지원금(구매자에게 지급)"과 "인수금(판매자에게 지급)"을 원문 그대로 방향까지 표시하고, 판매자가 캐피탈사·렌터카사 본인(리스렌트제휴)이면 라벨이 "선수금"으로 바뀌는 것까지 실측 확인했다. KB차차차의 "리스승계" 324건은 **국산차(69건)와 수입차(255건)의 판매자 구성이 다르다** — 표본으로 연 40건의 수입차(BMW·미니·볼보)는 전량 단일 딜러 그룹(코오롱모터스 BPS)이었지만, 국산차 쪽을 따로 열어보니 승계대행 전문법인("주식회사 탑기어모터스")이 **롯데렌터카 장기렌트 승계 계약을 KB차차차에 재게시**한 사례가 확인돼, 표본만으로 "리스승계=코오롱 독점"이라 단정할 수 없다. **롯데렌터카만 절차·수수료·분쟁 원칙을 명문화한 자사 게시판**을 운영하지만, "상호 간 연락 및 차량 확인 단계에서는 롯데렌터카의 개입 없이 직접 진행"이라고 명시해 자사 계약임에도 당사자 간 직거래로 선을 긋는다 — 반면 그 계약을 대신 광고하는 대행업체(탑기어)는 훨씬 상세한 7단계 심사 절차를 스스로 공개한다. 광고 요금은 3사 모두 승계 매물 전용 SKU가 없다(엔카는 국산/수입 구분만, KB는 리스승계 자체가 딜러 매물이라 별도 과금 노출 없음, 롯데는 승계수수료를 렌트료가 아닌 명의이전 행정비로만 규정). 차용 코드 관점에서는 엔카의 "총비용 = Σ월납입 + 만기비용 ± 승계지원금/인수금" 산식이, `calcTotalEffectiveCost`에 승계지원금·인도금 가감 항이 없다는 기존 발견(`2026-09-15-competitor-landscape.md` #1·#2)을 실측 수치로 재확인시켰다.

- 확인일은 모두 2026-09-15다. 엔카·KB는 Firecrawl이 iframe/SPA 렌더링을 막아(`automotive.encar.com is blocked` 오류, 또는 knockout 바인딩 미실행) Claude in Chrome으로 직접 렌더링해 읽었다. 엔카 목록 페이지의 정적 HTML은 EUC-KR 인코딩이라 `curl` + `iconv`로 원문 dot-template(카드 표시 로직)을 추출했다.
- **[확인]**은 1차 소스 원문(브라우저 렌더링 또는 curl 원문). **[코드]**는 업체 웹의 클라이언트 템플릿/스크립트에서 관찰한 로직. **[판단]**은 이 문서의 해석. **[미확인]**은 §10 참조.

## 1. 역할과 돈의 흐름

한 줄: 세 업체 모두 매도자·인수자 간 승계지원금/인도금은 당사자 직접 정산이고, 플랫폼은 등록비·광고비(엔카)만 받거나 무료(KB 직거래)이며, **롯데렌터카만 자사가 승계수수료(서류확인·명의이전 행정비)를 별도로 받는다** — 나머지는 플랫폼이 이 돈의 흐름에 개입하지 않는다.

## 2. 매도자 여정

한 줄: 엔카는 셀프등록(유료 이용권 구매) → 리스렌트구분/혜택구분 선택 후 게시, KB는 딜러가 절대다수이고 개인 직거래는 소수(리스승계는 수입=코오롱모터스 BPS 인증중고, 국산=승계대행업체가 재게시하는 혼재 구조, §7.2), 롯데렌터카는 **자사 계약 고객만** 로그인 후 승계 차량을 등록한다(타사 계약 차량 등록 불가).

## 3. 인수자 여정

한 줄: 엔카·KB는 목록에서 바로 판매자에게 연락(전화/문자, 050 안심번호)하는 광고형 구조이고, 롯데렌터카만 "구매 희망자의 차량 검색 → 상호 연락 → 영업매니저 심사(세이프키 인증절차 포함) → 합의서·수수료 납부 → 승계 완료"의 공식 6단계를 명문화했다.

### 4.2 엔카 — 리스 매물 (`fem.encar.com/cars/detail/42500055`, 카니발 하이리무진, 운용리스)

**[확인]** "리스 정보" 카드 원문: "차량 계약 시 비용 — 인수금 (판매자에게 지급) 100만원", "운행기간 동안 비용 — 월리스료 141만원×47개월 = 6,627만원", "리스 만기 후 비용 — 구매(리스사에게 지급)/반납(보증금 환급) 0만원", "총비용 6,727만원"(=6,627+100). 체크포인트: "리스방식 운용리스 · 승계지원금 없음". 목록 카드에 "**잔존가치가 낮은차량**" 경고 배지가 별도로 붙는다 — 매도자·엔카 어느 쪽도 아닌 시스템 산정 위험 신호로 보인다.

- 인수금(=차용 인도금) 방향이 원문에 "(판매자에게 지급)"으로 명시돼, `CONTEXT.md`의 "인도금: 인수자가 매도자에게 주는 현금" 정의와 정확히 일치함을 실측 확인했다.
- **총비용 산식(엔카, [확인])**: `총비용 = Σ(월납입×잔여개월) + 만기후비용 − 승계지원금 (있으면) + 인수금 (있으면)`. 렌트 사례(3,944−200=3,744)와 리스 사례(6,627+100=6,727) 양쪽에서 성립을 확인했다. 차용 `calcTotalEffectiveCost`(`src/lib/finance/calculations.ts`)에는 이 가감 항이 없다.

### 4.3 엔카 카드의 승계지원금·인수금 표시 규칙 [코드]

목록 페이지 정적 HTML(`dc_carleaselist.do?carType=kor`)에 내장된 dot-template 원문(EUC-KR, `curl`+`iconv`로 추출):

```
{{? val.AcceptanceCharge > 0 }}
    {{? it.isDataRentPartnership(val) }}
        선수금
    {{??}}
        인수금
    {{?}}
    {{=encarUtils.speedFormatCurrency(val.AcceptanceCharge)}} 만원
{{?? val.Succession > 0 }}
    승계지원금
    {{=encarUtils.speedFormatCurrency(val.Succession)}} 만원
{{?}}
```

즉 `AcceptanceCharge`(인수금)가 0보다 크면 인수금(제휴몰 매물이면 "선수금")을 표시하고, 그렇지 않고 `Succession`(승계지원금)이 0보다 크면 승계지원금을 표시한다 — **두 값이 카드에 동시에 노출되는 경우는 구조상 없다**(else-if).

**"선수금" 사례 실측 [확인]**: 목록에서 "현대 아이오닉6 롱레인지 익스클루시브 — 리스 — 선수금 885만원"을 찾아 상세(`fem.encar.com/cars/detail/42721599`)를 열었다. 판매자정보가 "**현대캐피탈|금융상담**"(딜러가 아니라 캐피탈사 본인)이었고, "현대캐피탈 리스 차량입니다", "엔카닷컴은 현대캐피탈의 대출 모집 업무를 대리·중개합니다"라는 고지가 있었다 — `isDataRentPartnership`가 참이 되는 조건은 **판매자가 캐피탈사·렌터카사 본인(리스렌트제휴)인 경우**로 확인된다. 이 매물에는 현대캐피탈이 직접 공시한 상품 조건도 있다: "중도해지 손해배상금: 미회수 원금×중도해지 손해배상금률(9~40%)", "**승계 수수료: 미회수 원금×승계 수수료율(0.5~2%)**", "가치 감가 금액: 반환 시점의 자동차의 기대 가치(또는 중고차 시세)×감가율(0~18%)". 마지막 항은 `2026-09-15-competitor-landscape.md` §4가 [2차, 공식 URL 에러]로 남겨둔 "현대캐피탈 승계수수료 0.5~2.0%"를 **[확인]으로 승격**시키는 1차 소스다.

### (b) 과금 시점과 주체

- 엔카: 등록 시 선불(이용권 차감). 광고 상품도 전부 선불.
- KB: 직거래는 무료라 과금 시점 없음. 리스승계는 딜러-KB 간 B2B 계약으로 소비자 화면에 노출 안 됨(미확인).
- 롯데렌터카: 승계수수료는 "합의서 작성 후" 납부(절차 05단계) — 즉 성사 후불에 가깝다. 주체는 "당사자 간 합의"로, 회사가 강제하지 않는다.

### (c) 결제 수단·PG

- 세 업체 모두 이번 조사 범위(비로그인)에서 결제 수단·PG사 정보는 노출되지 않았다. 엔카 이용권 결제 화면, KB 대출/리스 상담 신청, 롯데렌터카 승계수수료 납부는 모두 로그인 또는 상담 이후 단계라 미확인.

### (d) 안전결제·에스크로 흐름, 환불, 분쟁 처리

- **엔카**: 에스크로 없음. 안심 장치는 050 안심번호(통화 녹음)뿐. 승계지원금·인수금은 당사자 직접 정산(플랫폼 미개입).
- **KB차차차**: 에스크로 없음. "헛걸음보상"은 방문 예약 불이행에 대한 20만원 보상이지 거래대금 안전결제가 아니다. KB보증/KB프렌즈인증은 구매 후 고장에 대한 수리보증(최대 200만원, 1회 90만원 한도)이지 대금 예치가 아니다.
- **롯데렌터카**: 에스크로 없음. **분쟁 처리 원칙이 명문화된 유일한 사례** — "상호 간 연락 및 차량 확인 단계에서는 롯데렌터카의 개입 없이 직접 진행해주셔야 합니다"라고 원문에서 명시해, 자사 계약 차량임에도 매칭·확인 단계의 책임을 이전한다. 채권(미납 과태료·사고 면책금) 정산 책임도 매도자에게 지우고, 구매자에게도 "채권 확인"을 권고한다. 환불 규정은 원문에 없음(미확인).
