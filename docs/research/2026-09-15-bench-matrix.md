## 한 줄 결론

경쟁·관련 업체 19곳과 금융사 19곳을 차용과 한 표에 놓으면, 차용이 잡은 자리(등록·검수·채팅·예치까지 들어오는 카딩형)에서 코드가 아직 못 채운 것이 세 갈래로 모인다. (1) **승계지원금·인도금**을 방향 있는 필드로 갖지 못했고(`carryoverPremium` 하나, 음수 불가), 잔존가치·만기옵션·총 계약기간·선납금·포함항목이 스키마에 없다(1층 7곳이 가진 필드). (2) **"에스크로"**라 부르는 결제는 토스 에스크로 상품을 켜지 않은 일반 카드결제이고, 예치 대상은 가계약금 50만원+승계비뿐이며 인도금은 예치 대상이 아니다. 예치까지 개입하는 경쟁사는 카딩뿐이고 토스 자신이 무배송 거래에는 에스크로를 권하지 않는다. (3) **수수료**는 업계가 등록비 선불 + 성사 시 정률(1.5~4%, 최소 60~77만원) 또는 정액(165만원)이고 금융사는 정률 0.5~2%×잔여비율+상한이 표준인데, 차용 Phase 1은 빠른승계 정액 30만원·일반 무료이고 코드는 수수료 필드를 채우지 않는다. Phase 1 결정 충돌 후보는 결정 지점 **53개**(A~J)로 압축했고(§8), 웹으로 못 닫는 항목 **132건**은 별도 목록에 있다(§9). 결정은 이 문서가 내리지 않는다.

## 0. 읽는 법

- **행**: 1층 직접 경쟁 9곳 → 2층 플랫폼·렌터카사 채널 4곳 → 3층 견적 중개 6곳 → 차용. 금융사 21곳은 §6에 따로.
- **차용은 두 행**. `차용(코드)`는 커밋 97d6c2b의 스키마·계산기·결제 코드가 실제로 하는 것, `차용(Phase 1)`은 스펙 `2026-05-06-chayong-phase-1-scope.md`가 정한 것. 둘이 다르면 그 자체가 결정 지점이다(§8).
- **상충 값**: 출처끼리 다른 값은 `1.5% / 1%(상충·웹 밖)`처럼 둘 다 적는다. 웹으로 해소된 상충은 해소값만 적고 `(해소, gaps §3)`을 붙인다. 판정은 이 문서가 내리지 않는다.
- **태그**: [확인] 1차 원문 / [코드] 업체 웹 소스·차용 코드 / [2차] 기사·DB / [판단] 해석 / [미확인]. 원문서의 태그를 그대로 옮겼다.
- **출처**: `(carding §8)`은 `docs/research/2026-09-15-bench-carding.md`의 8절. 상세·URL·확인일은 그 문서에 있다. 확인일은 전부 2026-09-15.
- **여정 기호**: ● 플랫폼이 직접 수행·보유 / ◐ 대행·지원·안내 / ○ 당사자끼리 / — 해당 없음 / ? 미확인.
- 2차 조사(리뷰·인프라·규제·채널)는 열로 펼치지 않고 §7 "설계 조건"에 요약했다. 리뷰의 불만 유형만 §5 표에 한 열로 넣었다.

## 8. Phase 1 결정 충돌 후보 → 후속 결정 지도 입력

이 절은 결정을 내리지 않는다. 15개 문서가 "차용 결정과 다르다"고 적은 후보를 **결정 지점**(질문 하나 = 후속 지도의 티켓 하나) 단위로 압축했다.

### 8.0 배치 원칙

- 각 결정 지점은 **그 지점이 막는 결정이 무엇인가**를 기준으로 그룹 A~J 중 하나에 배치한다. 문서 출처 위치가 아니라 논지 기준.
- 두 그룹에 걸치는 항목은 주 그룹에 행을 두고 다른 그룹에는 `(교차: X)`로만 표기, 행을 중복 생성하지 않는다.
- Phase 1 스펙(`2026-05-06-chayong-phase-1-scope.md`)은 **Q18~Q36만 상세 기재한다.** 문서 제목·Status는 "Q1~Q37"이라 하지만(L4-5), 본문은 "Q1~Q17은 매물 데이터 모델·비즈니스 수익·벤치마킹 영역으로 본 spec엔 Q18~Q37만 포함, Q1~Q17 결정은 별도 문서화 보강 필요"라고 명시하고(L18), 실제로 `### Q37` 절은 존재하지 않는다(grep 0건). 즉 **Q1~Q17이 통째로 미기재 상태**이며, 아래 A·F 그룹(매물 데이터 필드·지원금 방향)의 다수 지점이 바로 이 공백에 해당한다. 관련 Q 번호가 "없음"인 지점은 대부분 이 사유다.

### 8.3 집계

- 결정 지점 수: **53개** (A3·B3·C7·D6·E4·F8·G4·H7·I9·J2)
- 원본 후보 수: 1차 61건 + 2차 60건(신규25/보강14/영향없음21) = 121건 (집계 방법이 서로 달라 단순 합산은 참고용)
- 압축률: 결정 지점에 실제로 반영된 원인 문장 86건(1차61+2차신규25) → 53개 지점, `(86-53)/86 ≈ 38%`. 1차 61건은 32개 지점에, 2차 신규 25건은 21개 지점에 독자 반영 + 4건 교차흡수 (§2 병합 결과 참조)
